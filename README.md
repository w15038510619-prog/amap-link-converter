# 高德/百度位置链接转地图导入模板工具

这是一个专为 Windows 10/11 环境设计的 Python 批处理与日常小工具，用于将 Excel 表格中的点位名称和地图位置链接批量提取为高精度的 **GCJ-02 火星坐标系经纬度**，并严格按照地图导入模板格式导出。

---

## 一、核心特性与设计原则

1. **严格遵守模板规范**：
   - 输出文件主数据页严格命名为 `标记位置`，包含 9 列固定表头：`名称`、`*经度`、`*纬度`、`*地址`、`颜色`、`图标(外轮廓)`、`图标(填充物)`、`描述`、`文件夹`。
   - 经纬度写入为浮点数值型（GCJ-02 坐标系），地址字段留空，不改动星号或列顺序。
   - 自动清除原模板第 2 行起的旧历史测试数据，仅写入本次转换结果，杜绝数据混杂。
   - 完整保留模板中的另外两个说明工作表（`导入说明`、`颜色说明`）及其嵌入的示意图片。
   - 始终生成新文件副本，原模板文件及源数据表绝对不被覆盖。

2. **输入表结构自适应识别**：
   - 完美兼容 `.xlsx`（openpyxl）与旧版 `.xls`（xlrd）格式。
   - 自动扫描工作簿内所有非空工作表，跳过空白表。
   - 支持常见表头组合（如 `序号/台区/位置`、`台区/链接`、`序号/台区名称/高德地址`）。
   - **智能识别无表头模式**：当表格仅有两列（名称、链接）且无表头时，第一行数据不会被丢弃。
   - 全面支持单元格明文文本、真实超链接（`cell.hyperlink.target`）及 `HYPERLINK("url", ...)` 静态公式提取。对于动态公式拼接则进行安全拦截并记入待处理明细。
   - 保留名称中的 `#`、全角 `＃`、空格、数字等原文内容，仅去除首尾空白字符，同名不同点位保持独立，不盲目去重。

3. **全覆盖的高德与百度地图链接解析**：
   - **核心提取原则**：严格取**目的地（终点）**，杜绝误取起点、手机当前位置、中途途经点或地图视图中心。
   - **高德导航路径 `__r=`**：兼容无 `?` 查询前缀的 URL 路径形式，精确提取第 2 组终点（纬度、经度）并调优为输出（经度、纬度）。
   - **高德网页路由 `r=`**：支持 `amap.com/?r=...` 无协议或有协议路由。
   - **高德 `daddr=` 参数**：提取经度、纬度；若与 `__r` 同时存在，自动进行交叉核对，若目的地冲突则安全报错转待处理。
   - **高德 `to[lnglat]` 参数**：提取目的地坐标，严格忽略 `from[lnglat]`。
   - **高德嵌套 `schema` 协议**：解码 `amapuri://route/plan` 协议，乱序提取目的地 `dlon` 与 `dlat`，杜绝使用起点 `slon/slat`。
   - **高德实时动态分享页**：对缺少明文坐标的分享链接，独立封装调用高德公开接口（`https://m5.amap.com/ws/user/route/share/info`），具备超时重试、令牌脱敏及网络故障隔离机制，离线数据不受影响。
   - **百度地图 `en=` 终点**：提取 `map.baidu.com/dir/...` 中的 `en` 终点，精准识别百度墨卡托大数值平面坐标（BD09MC），使用经过回归核验的百度逆投影多项式转换为 BD-09 经纬度，再转换为 GCJ-02；忽略 `sn=` 起点与 `@` 视图中心。

4. **异常隔离与记录数守恒**：
   - 单条记录异常绝不中断批处理流程。
   - 严格满足：**识别到的业务记录总数 = 成功导入数 + 待处理数**。
   - 当有点位因超长（>40字）、链接为空、链接失效或格式错误时，自动生成 `<源文件名>_待处理明细_<时间戳>.xlsx`，清晰列出原行号、原内容与失败原因，便于人工核对。
   - 若全部记录失败，杜绝输出空导入文件伪装成功，直接生成待处理明细并明确告警。

## 二、安装与环境准备

本项目优先采用 Python 标准库，外部依赖保持极简。

### 1. 系统要求
- Windows 10 / 11
- Python 3.8 及以上（推荐 Python 3.10+）

### 2. 安装依赖
在项目根目录下打开 PowerShell 或 CMD 命令行执行：
```bash
python -m pip install -r requirements.txt
```

`requirements.txt` 包含：
- `openpyxl>=3.1.2`：用于读写 `.xlsx` 文件及图表保留
- `xlrd>=2.0.1`：用于读取 `.xls` 旧版表格
- `requests>=2.28.0`：用于高德动态分享页解析（若缺失会自动降级使用标准库 urllib）
- `pillow>=9.0.0`：用于 openpyxl 图片资源安全保存
- `pytest>=7.0.0`：用于运行自动化测试套件

## 三、使用方式

支持**图形弹窗选择（GUI）**与**命令行批量运行（CLI）**两种方式。

### 模式 A：图形弹窗交互（日常最简使用）

#### 1. 直接双击运行 EXE（推荐，无需 Python 环境）
直接进入 `dist/` 目录，双击运行：
```text
地图链接批量转换工具.exe
```
程序自带 Python 运行环境与所有依赖，双击后将自动依次弹出 3 个标准文件选择框：
1. **选择待处理源文件**：支持按住 `Ctrl` 键同时多选多个 `.xlsx` 或 `.xls` 文件。
2. **选择导入模板**：默认检测当前目录或 EXE 同级目录下的 `导入模板 (9).xlsx`。
3. **选择输出目录**：选择转换结果保存的文件夹。
转换完成后会自动弹出统计提示框，并提示按回车安全退出。

#### 2. Python 源码运行
直接在命令行中不加任何参数运行：
```bash
python main.py
```
或
```bash
python map_link_converter.py
```

> 若在任意步骤点击“取消”，程序将安全退出，不会产生任何垃圾文件。

---

### 模式 B：命令行批处理（适合自动化脚本）
使用命令行参数直接指定路径，完全静默运行，无需界面点击：

使用 EXE：
```bash
dist\地图链接批量转换工具.exe -i "新建 XLSX 工作表.xlsx" -t "导入模板 (9).xlsx" -o "./导出结果"
```

使用 Python：
```bash
python main.py -i "新建 XLSX 工作表.xlsx" -t "导入模板 (9).xlsx" -o "./导出结果"
```

#### 命令行参数说明：
- `-i, --input`：待处理的 Excel 源文件路径（支持传入多个文件，以空格隔开）。
- `-t, --template`：地图导入模板文件路径（`.xlsx` 格式）。
- `-o, --output-dir`：输出结果保存目录（不存在时自动创建）。
- `--offline`：（可选）离线模式，禁止访问网络请求高德分享接口。

## 四、输出文件说明

对于每一个处理的源文件，转换完成后将在输出目录下生成：

1. **地图导入文件**（存在成功记录时生成）：
   - 命名格式：`<源文件名>_地图导入_<年月日_时分秒>.xlsx`
   - 主表 `标记位置` 写入符合规范的点位名称与数值型 GCJ-02 经纬度。
2. **待处理明细文件**（存在失败/异常记录时生成）：
   - 命名格式：`<源文件名>_待处理明细_<年月日_时分秒>.xlsx`
   - 包含列：`源文件名`、`工作表`、`原行号`、`点位名称`、`原始位置内容`、`超链接目标`、`解析模式`、`中间信息/坐标系`、`失败原因`。
3. **中文运行日志**：
   - 命名格式：`converter_<年月日_时分秒>.log`
   - UTF-8 编码，记录逐文件处理进度、成功/待处理统计及异常堆栈。

## 五、自动化测试

本项目配套了完整的自动化测试用例，覆盖所有链接类型、坐标转换回归样例、Excel 表头自适应、图片保留及端到端流程：

在项目目录下执行：
```bash
python -m pytest -v
```

测试集涵盖：
- `test_coord_transform.py`：BD09MC 回归样例 (13145007, 2792306) -> BD-09 -> GCJ-02 精度验证、坐标合法性与异常边界测试。
- `test_coord_extractor.py`：高德 `__r`、`r=`、`daddr=`、`to[lnglat]`、乱序 schema、百度 `en=`、冲突检测、非合法链接拦截测试。
- `test_amap_api.py`：高德分享接口模拟响应测试（成功、超时、失效、缺字段）及真实请求验证。
- `test_excel_io.py`：`.xlsx` 与 `.xls` 读写、无表头第一行保留、真实超链接提取、静态/动态 HYPERLINK 公式处理、坏链接隔离、名称超长不截断测试。
- `test_end_to_end.py`：使用附件《新建 XLSX 工作表.xlsx》和《导入模板 (9).xlsx》进行完整真实转换并核验输出文件。

## 六、EXE 打包与重新编译说明

如果修改了代码需要重新生成单文件版 `.exe`，可在项目根目录下执行以下命令：

```bash
python -m PyInstaller --noconfirm --onefile --name "地图链接批量转换工具" --add-data "导入模板 (9).xlsx;." main.py
```
生成的独立可执行文件将保存在 `dist/地图链接批量转换工具.exe`。
